# Akiwi.at

Каталог халяль-френдли ресторанов в Австрии. Next.js 15 (App Router), React 19, деплой на Vercel из GitHub `NSM1276/akiwi.at`. Живой сайт: https://www.akiwi.at

## Обязательно прочитать перед работой

- `docs/AUDIT-2026-09-18.md` — аудит проекта, принятые решения и порядок работ. Решения из раздела 3 действуют, пока владелец не изменит их.

## Ключевые решения (кратко)

- Данные живут в JS-файлах в `data/`, владелец вносит их вручную. Никакой базы данных и админки, пока владелец не скажет иначе.
- Источник правды по заведениям — `data/venues.js`, по сетям — `data/chains.js`. Статус верификации хранится только в записи заведения; статус сети вычисляется из филиалов (минимальный по филиалам, `data/listing.js`).
- Карточки для главной и поиска собирает `getListing()` в `data/listing.js`. Вызывать только из серверных компонентов (`app/page.jsx`, `app/search/page.jsx`) и передавать пропсом в клиентские `HomeClient` / `SearchClient`, чтобы 370 KB `venues.js` не попали в клиентский бандл.
- Тексты интерфейса: `data/data.js` (общие), `data/search-data.js` (поиск), `data/detail-copy.js` (страница заведения).
- Посадочные страницы по городам, венским районам и категориям собирает `data/landing.js`, адреса — `data/slugs.js`. Списки на них — настоящие заведения с адресами, а не карточки сетей. Категория получает страницу от двух заведений; комбинации «город + категория» намеренно не делаем.
- SEO: базовый URL `https://www.akiwi.at`, `app/sitemap.js` и `app/robots.js` генерируются из данных, JSON-LD собирает `data/jsonld.js`. Карточки на главной и в поиске — настоящие `<Link>`, не `onClick`; сохраняй это при любых правках карточек. На `/search` `useSearchParams` живёт только в `QuerySync`, чтобы список рендерился статически.
- Фильтры: варианты выводит `getFacets()` из данных, руками списки не писать. Новый фильтр добавляем только если под него есть поле в `venues.js`. Часы работы попадают в карточки поиска через `getListing({ withHours: true })`, «Jetzt geöffnet» считается в браузере (`isOpenNow`), на сервере фильтр не применяется.
- Мобильные стили живут в `app/globals.css` (классы `search-layout`, `search-sidebar`, `search-filters`, `search-hero-fields`, `ak-nav-burger`), не в инлайновых `<style>`.
- Язык хранится только в `components/LangProvider.jsx` (ключ `akiwi.lang`), страницы берут его хуком `useLang()`. Текущее время — `components/useNow.js`, на сервере возвращает `null`. Оба на `useSyncExternalStore`, без `setState` в эффекте: линтер это запрещает.
- Шрифт подключается через `next/font/google` в `app/layout.jsx`, локальных файлов шрифтов в репозитории нет.
- Перед сдачей работы: `npm run lint` и `npm run build` должны проходить без ошибок.
- Не добавляем элементы интерфейса без работающей логики. Форма подписки, кнопки отзыва и жалобы удалены до появления бэкенда.
- Статусы verified / self / unknown оставляем как записаны. Текст под «Verifiziert»: «Halal-Status laut Betreiber bzw. Website des Lokals bestätigt.»
- Страницы Impressum / Datenschutz / for-owners / about пока не создаём. Ссылки на них из навигации убраны до появления страниц.
- Фейковые демо-рестораны и захардкоженные цифры («142 Lokale») удаляются, не возвращать.

## Структура

- `app/` — роуты: `/`, `/search`, `/r/[id]` (заведение), `/chain/[id]` (сеть), `/[city]`, `/wien/[district]`, `/kategorie/[slug]` (посадочные)
- `components/` — актуальные компоненты
- `data/` — данные и тексты DE/EN
- `src/`, HTML-файлы в корне, `tweaks-panel.jsx` — устаревший прототип, подлежит удалению (этап 5 аудита)

## Команды

```bash
npm run dev
npm run build
```
