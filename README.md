# Akiwi.at

Каталог халяль-френдли ресторанов в Австрии: 87 заведений, объединённых в 19 сетей и 10 одиночных мест, в Вене, Граце, Линце, Зальцбурге, Инсбруке и ещё пяти городах.

Живой сайт: **https://www.akiwi.at**

## Стек

Next.js 15 (App Router) · React 19 · Tailwind 4 · деплой на Vercel из ветки `main` репозитория `NSM1276/akiwi.at`.

Все 150 страниц генерируются статически на этапе сборки: заведения, сети и посадочные страницы по городам, венским районам и категориям. Базы данных нет: данные лежат в JS-файлах и версионируются вместе с кодом.

## Запуск

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на http://localhost:3000 |
| `npm run build` | Production-сборка, генерирует все статические страницы |
| `npm start` | Запуск собранного сайта |
| `npm run lint` | ESLint |

## Как добавить заведение

1. Скопировать шаблон из конца `data/venues.js` и вставить в объект `VENUES`, заполнив поля.
2. Если это филиал сети — добавить его `id` в `venueIds` нужной сети в `data/chains.js`. Если заведение одиночное, больше ничего делать не нужно: главная, поиск, карта и sitemap подхватят его сами.
3. Закоммитить и запушить. Vercel развернёт изменения примерно за минуту.

## Как поменять статус верификации

Одно поле `status` в записи заведения в `data/venues.js`: `'verified'`, `'self'` или `'unknown'`.

Статус сети нигде не хранится: он выводится из филиалов и равен самому низкому среди них. Сеть считается verified, только если verified все её филиалы.

## Правила, которых придерживаемся

- **Никаких выдуманных данных.** Если поля нет, элемент не показывается. Рейтинг выводится только при `reviews > 0`, фильтр появляется только если под него есть данные в `venues.js`.
- **Варианты фильтров выводятся из данных** функцией `getFacets()`, руками списки не пишем.
- **Карточки — настоящие ссылки** `<Link>`, а не обработчики клика, иначе поисковики не найдут внутренние страницы.
- **`data/listing.js` и `data/venues.js` только на сервере.** Вызывать `getListing()` в серверном компоненте и передавать результат пропсом, иначе 370 КБ данных уедут в браузер.
