# Этап 7 — видимость в поиске Google

Дата: 2026-10-03. Основа — данные Search Console за 18–29.09.2026.

## Что показал Search Console

- 14 кликов, 1 490 показов, CTR 0,9 %, средняя позиция 14,5. Проиндексировано 111 страниц, 41 «обнаружена, не проиндексирована».
- Почти весь спрос — названия заведений: `liwan` (поз. 5), `liwan restaurant` (4,8), `le döner` (9,4), `türkis scs` (12), `vapiano klagenfurt` (6,2), `bakis schnitzelparadies` (5,4), `damla bäckerei` (9,9). Страницы заведений стоят на первой странице, но CTR ≈ 0 %: заголовок и описание в выдаче не отвечают на то, что ищут.
- Люди ищут меню и часы: `liwan restaurant karte`, `pizzamann öffnungszeiten`, `rezensionen für damla`.
- Есть запросы на арабском: `مطعم ليوان` (22 показа).
- Запросы по районам работают: `shawarma 1120` (поз. 4,8), `/wien/1060-mariahilf` CTR 26,7 %.
- Общие запросы далеко: `halal restaurant` (36,8), `halal burger` (57,5), `halal essen in der nähe` (55,4). Главная — средняя позиция 58,9: её H1 — только логотип «akiwi.at».

## Найденные проблемы

1. Заголовок страницы заведения: «Liwan Restaurant Meidling — Meidling» — район дважды, нет «Wien», нет «Speisekarte», «Öffnungszeiten». Описание — только слоган и адрес.
2. На странице заведения нет связного текста — только списки. Филиалы одной сети почти одинаковые → «обнаружена, не проиндексирована».
3. JSON-LD: `aggregateRating` у 53 заведений, хотя отзывов на сайте нет (`reviews_list` пуст у всех). Это нарушение правил Google для разметки отзывов — риск ручных санкций.
4. JSON-LD: `servesCuisine` содержит «Restaurant»/«Imbiss»; тип всегда `Restaurant`; нет ссылки на меню.
5. Главная: H1 = логотип, заголовок и описание статичные, нет разметки `WebSite`/`Organization`.
6. Нет страниц под запросы о блюдах («halal burger»), хотя данные есть: бургер в меню у 23 заведений, фалафель у 26, баклава у 24.
7. `sitemap.xml`: `lastModified` = время сборки у всех страниц — Google учится его игнорировать.
8. Исправление горизонтального «плавания» на мобильном (`Map.jsx`) не закоммичено.
9. Редирект `akiwi.at → www.akiwi.at` — 307 (временный) вместо 308.

## Что делаем

- `data/seo.js` — заголовок, описание, абзац «Über …» и вопросы-ответы для страницы заведения, всё из полей записи (часы, меню, статус, адрес, удобства). Ничего не выдумываем: вопрос про доставку появляется, только если доставка отмечена.
- Страница заведения: новый текстовый блок, блок «Häufige Fragen», ссылки на блюда и сеть, раздел «Karte» → «Speisekarte».
- JSON-LD: убрать `aggregateRating`, тип по категории (`FastFoodRestaurant`, `CafeOrCoffeeShop`, `Bakery`), `servesCuisine` без типов заведений, `hasMenu`, `FAQPage`.
- Сеть: заголовок с городами, описание с адресами филиалов.
- Главная: настоящий H1, заголовок и описание из данных, `WebSite` + `Organization`.
- Посадочные: в описании района — названия заведений; у категорий «Wien & Österreich», если большинство в Вене.
- Новые страницы `/gericht/[slug]` из меню (минимум 3 заведения): список заведений с найденными блюдами и ценами.
- `sitemap.xml`: `lastModified` из последней даты `verification_log`.
- Коммит `Map.jsx`, редирект 308.

## Сознательно не делаем

- Арабскую версию: нет данных на арабском, переводить названия заведений сами не будем.
- Отзывы и рейтинги в интерфейсе не трогаем — убираем только из разметки для Google.
